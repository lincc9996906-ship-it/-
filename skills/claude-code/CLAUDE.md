# 梅花易数起卦工具

## 何时使用

用户问"起卦"、"算卦"、"梅花易数"、"解卦"或用易经分析问题。

## 使用方法

### 铜钱起卦（推荐）

```bash
python -m meihua_yi.cli --json --method coin --question "用户问题"
```

### 时间起卦

```bash
python -m meihua_yi.cli --json --method time --question "用户问题"
```

## 解卦流程

1. 运行上面命令获取 JSON 输出
2. 解析 JSON 中的 main_gua、mutual_gua、changed_gua、ti、yong
3. 按以下框架分析：

**体用五行生克：**
- 用生体 → 大吉
- 体用比和 → 平顺
- 体克用 → 可成但费力
- 体生用 → 泄气不利
- 用克体 → 大凶

**分析结构：**
1. 主卦含义
2. 体用关系
3. 互卦（发展过程）
4. 变卦（最终走向）
5. 动爻解读
6. 综合建议

## 输出格式

用简洁的中文输出，包含卦象摘要和解卦内容。不要列资料清单，给出明确结论。
